# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/adg-ub/omarchy-bay-transit-board/security/advisories/new).
Do not include exploit details in a public issue.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Reports will be acknowledged as soon as practical and coordinated
disclosure will be used for confirmed issues.

## Supported versions

Security fixes are provided for the latest released version. Users should keep
the plugin current with:

```sh
omarchy plugin update io.github.adg-ub.bay-transit-board
```
